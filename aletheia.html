FAQ

What is Aletheia?

Four OFX plugins for DaVinci Resolve that simulate photochemical film processing from spectral data.

Is it a subscription?

No. One-time purchase, free updates.

What's included in the trial?

All four plugins, unlimited time. Output is watermarked.

How many machines can I activate?

Two machines per license.

What cameras are supported?

Any camera DaVinci Resolve supports.
Alpha handles the color space conversion.

Do I need all four plugins?

They're designed as a suite but each works independently.

Does it work with Resolve Free?

Yes, both Free and Studio.

How do I install it?

Download the installer, run it, restart Resolve.
